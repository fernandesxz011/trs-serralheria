# T.R.S Serralheria — site

Site estático em HTML, CSS e JavaScript, pronto para editar no VS Code com o Codex.

## Abrir

1. Extraia o ZIP.
2. Abra a pasta `trs-export` no VS Code.
3. Abra `index.html` no navegador ou use a extensão Live Server.

## Estrutura

- `index.html`: conteúdo, estilos e efeitos.
- `assets/fachada.jpeg`: fotografia usada para mostrar o símbolo original da placa.

Os botões de orçamento levam à seção de contato. Para ativar o WhatsApp, adicione o número oficial da empresa e substitua os links correspondentes.
